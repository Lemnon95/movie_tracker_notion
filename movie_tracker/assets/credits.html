This application uses TMDB and the TMDB APIs but is not endorsed, certified, or otherwise approved by TMDB.

TMDB provides primary movie metadata. Visit The Movie Database.

OMDb provides IMDb ratings and fallback metadata. OMDb legal terms.

Privacy and permitted use

Movie Tracker is intended for personal, non-commercial use. Commercial use of provider APIs requires the appropriate provider agreements.

Movie Tracker has no telemetry or author-operated backend. Credentials are stored unencrypted in the local config.json file. Requests go directly from your computer to Notion, TMDB, and OMDb.

Each user must create and control their own API credentials. Revoke those credentials and delete the local config.json if you stop using the application or believe the file has been exposed.
